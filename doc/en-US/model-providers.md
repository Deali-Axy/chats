# Supported Model Providers

**English** | [简体中文](../zh-CN/model-providers.md)

Ayaka Chats can connect to multiple providers through **Model Keys** and **Model Configuration** in the administration area, including OpenAI, Azure AI Foundry, Anthropic, Google AI, DeepSeek, Ollama, OpenRouter, Doubao, MiniMax, and Qwen.

When adding a model, provide its provider name, API endpoint, credentials, and compatible protocol. Supported protocols include OpenAI Chat Completions, Responses, Anthropic Messages, Google Gemini, and image-generation APIs.

Model capabilities and billing differ by provider; consult the provider's official documentation.
