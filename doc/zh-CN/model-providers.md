# 支持的模型提供商

[English](../en-US/model-providers.md) | **简体中文**

Ayaka Chats 可通过后台的“模型密钥”和“模型配置”接入多个模型提供商，包括 OpenAI、Azure AI Foundry、Anthropic、Google AI、DeepSeek、Ollama、OpenRouter、火山方舟、MiniMax、通义千问等。

添加模型时，请填写提供商名称、API 地址、凭据和兼容的协议类型。支持 OpenAI Chat Completions、Responses、Anthropic Messages、Google Gemini 及图像生成接口。

不同提供商的模型能力和计费规则不同，请以其官方文档为准。
